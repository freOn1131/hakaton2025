ВАЖНЫЕ ПРАВИЛА:
1. Верни ТОЛЬКО валидный JSON без дополнительного текста
2. Если какие-то данные отсутствуют, используй null для этих полей
3. Числовые поля должны быть числами, а не строками
4. Массивы financial_data и personnel_data должны содержать данные за доступные годы (обычно 2022, 2023, 2024)
5. Если в исходных данных указаны какие-то описания полей (например, "Указать цифровое значение"), замени их на null
6. ИНН должен быть строкой из 10 или 12 цифр
7. Координаты должны быть в десятичном формате (например, 55.802968, 37.580095)

Исходные данные для разбора:

{input_data}

Верни ТОЛЬКО JSON, без любых других текстов!
