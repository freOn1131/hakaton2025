ВАЖНЫЕ ПРАВИЛА ИЗВЛЕЧЕНИЯ ДАННЫХ:

1. **Формат ответа**: Верни ТОЛЬКО валидный JSON без дополнительного текста, комментариев или пояснений
2. **Отсутствующие данные**: Если какие-то данные отсутствуют в исходном тексте, используй `null` для этих полей
3. **Типы данных**: 
   - Числовые поля (revenue, profit, площади, количество сотрудников) должны быть числами, а не строками
   - Строковые поля должны быть строками
   - Не оставляй пустые строки "", используй null если данных нет
4. **Массивы данных**: 
   - financial_data и personnel_data должны содержать данные за доступные годы (обычно 2022, 2023, 2024)
   - Каждый год - отдельный объект в массиве
   - Если данных за какой-то год нет, пропускай этот год
5. **Обработка текстовых описаний**: Если в исходных данных указаны описания полей (например, "Указать цифровое значение", "Перечислить государства"), замени их на `null`
6. **ИНН**: Должен быть строкой из 10 или 12 цифр. Проверяй корректность.
7. **Координаты**: Должны быть в десятичном формате (например, 55.802968, 37.580095). Если указаны градусы-минуты-секунды, конвертируй в десятичный формат.
8. **Даты**: Формат ДД.ММ.ГГГГ (например, 15.03.2010)
9. **Финансовые показатели**: Всегда в тысячах рублей. Если указаны в других единицах (млн, млрд), конвертируй в тысячи.
10. **Адреса**: Полные адреса с индексом, если он указан
11. **Статус**: Только один из вариантов: "Действующая", "Ликвидирована", "В стадии ликвидации", "Реорганизуется"
12. **Округа Москвы**: САО, СВАО, ВАО, ЮВАО, ЮАО, ЮЗАО, ЗАО, СЗАО, ЦАО, ЗелАО, ТАО, НАО

АЛГОРИТМ ОБРАБОТКИ:

1. Внимательно прочитай весь предоставленный текст
2. Определи, какие поля можно извлечь из текста
3. Для каждого поля извлеки соответствующее значение
4. Преобразуй значения в нужный тип данных
5. Для массивов financial_data и personnel_data сгруппируй данные по годам
6. Проверь корректность JSON структуры
7. Верни только JSON без дополнительного текста

ПРИМЕРЫ ИЗВЛЕЧЕНИЯ:

Если в тексте: "Выручка 2022: 1500000 тыс.руб., 2023: 2000000 тыс.руб."
Извлеки:
```json
"financial_data": [
  {"year": 2022, "revenue": 1500000},
  {"year": 2023, "revenue": 2000000}
]
```

Если в тексте: "Численность сотрудников в Москве: 2022 - 50 чел., 2023 - 60 чел."
Извлеки:
```json
"personnel_data": [
  {"year": 2022, "moscow_employees": 50},
  {"year": 2023, "moscow_employees": 60}
]
```
