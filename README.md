## 🎯 О проекте

**Система управления данными предприятий Москвы** — это комплексное веб-приложение для автоматизации работы с информацией о промышленных предприятиях столицы. Проект решает ключевую проблему: **сложность сбора и обработки разрозненных данных о предприятиях** из различных источников.

### Проблема

Государственные органы и сами предприятия сталкиваются с необходимостью:
- Вручную собирать данные из множества источников (ФНС, отчетность, документы)
- Обрабатывать неструктурированную информацию (PDF, Excel, текст)
- Поддерживать актуальность данных о сотнях организаций
- Анализировать показатели по отраслям

### Решение

Наша система автоматизирует весь цикл работы с данными:

1. **Автоматический сбор** - интеграция с API ФНС, DaData, СПАРК Интерфакс
2. **Интеллектуальная обработка** - парсинг документов с помощью нейросети (LLM)
3. **Централизованное хранение** - единая база данных с полной историей
4. **Аналитика и отчетность** - интерактивные дашборды и экспорт в PDF

### Для кого

- 🏛️ **Департамент инвестиционной и промышленной политики** - мониторинг предприятий
- 🏢 **Промышленные предприятия** - управление собственными данными
- 📊 **Аналитики** - исследование отраслевых показателей
- 🔍 **Инвесторы** - оценка промышленного потенциала города

## ⚡ Возможности

### 🔍 Поиск и получение данных

#### Интеграция с внешними API
- **API ФНС** - получение актуальных данных из ЕГРЮЛ/ЕГРИП
- **DaData** - валидация и обогащение адресных данных
- **СПАРК Интерфакс** - расширенные справки о компаниях

#### Поиск в базе данных
- Быстрый поиск по ИНН или названию
- Фильтрация по отраслям и округам
- Полнотекстовый поиск по всем полям

### 🤖 Интеллектуальная обработка данных

#### Парсинг документов с помощью AI
Система использует нейросеть **Gemma 3:27B** для автоматического извлечения структурированных данных из:

- 📄 **PDF документы** - годовые отчеты, презентации, справки
- 📊 **Excel файлы** - финансовые данные, реестры предприятий
- 📝 **Текстовые данные** - любая неструктурированная информация

**Извлекается 108 полей:**
- Основные реквизиты (ИНН, названия, адреса, ОКВЭД)
- Финансовые показатели по годам (выручка, прибыль, налоги)
- Данные о персонале (численность, зарплата, ФОТ)
- Информация о недвижимости (кадастр, площади)
- Производственные данные (продукция, ОКПД 2, экспорт)

### 📊 Аналитика и визуализация

#### Детальная информация об организациях
- Все реквизиты и контакты
- Финансовые показатели за 3 года
- Данные о персонале и зарплатах
- **4 интерактивных графика:**
  - Динамика выручки (столбчатая диаграмма)
  - Динамика прибыли (линейный график)
  - Численность сотрудников (столбчатая диаграмма)
  - Средняя зарплата в Москве (линейный график)

#### Отраслевая аналитика
- **Дашборды по отраслям:**
  - Распределение выручки (круговая диаграмма)
  - Численность по организациям (столбчатая диаграмма)
  - Динамика развития отрасли (линейный график)
- **Статистика:**
  - Количество предприятий в отрасли
  - Суммарная выручка
  - Средняя численность сотрудников
- **Экспорт отчетов в PDF** - с графиками и таблицами

### ✏️ Управление данными

#### Редактирование организаций
- Выбор организации из списка
- Редактирование всех 33 полей основных данных
- Обновление финансовых показателей
- Изменение данных о персонале

#### Добавление новых организаций
- Ручной ввод данных

- Автоматическое заполнение полей

## 🛠 Технологии

- **Python 3.8+** - основной язык программирования

- **SQLite** - база данных
- **PyPDF2** - парсинг PDF документов

- **Gemma 3:27B** - большая языковая модель для парсинга

- **DaData API** - валидация адресов и реквизитов
- **СПАРК Интерфакс API** - бизнес-справки

## 🚀 Быстрый старт

### Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)
- 500 МБ свободного места на диске

### Установка

1. **Клонируйте репозиторий**

```bash
git clone https://github.com/freOn1131/hakaton2025.git
cd hakaton2025
```

2. **Установите зависимости**

```bash
pip install -r requirements.txt
```

Зависимости:
- Flask==3.0.0
- PyPDF2==3.0.1
- requests==2.31.0
- openpyxl==3.1.2

3. **Настройте API ключи**

Откройте `app.py` и укажите ваши ключи:

```python
# API ФНС
FNS_API_KEY = "your_fns_api_key"

# LLM API
LLM_API_KEY = "your_llm_api_key"
LLM_API_URL = "http://your-llm-server:8080/api/chat/completions"
```

Где получить ключи:
- **API ФНС**: https://api-fns.ru (от 1000 руб/год)
- **DaData**: https://dadata.ru (есть бесплатный тариф)
- **СПАРК**: https://spark-interfax.ru (по договору)

4. **Инициализируйте базу данных**

```bash
# База создастся автоматически при первом запуске
# Или удалите старую для пересоздания:
rm organizations.db
```

5. **Запустите приложение**

```bash
python app.py
```

6. **Откройте в браузере**

```
http://localhost:8188
```

## 🔌 API документация

### Аутентификация

#### `POST /api/auth/login`

Вход в систему.

**Request:**
```json
{
  "username": "admin",
  "password": "admin"
}
```

**Response:**
```json
{
  "status": "success",
  "user_id": 1,
  "username": "admin"
}
```

---

### Поиск

#### `GET /api/fns/search/<inn>`

Поиск организации через API ФНС.

**Parameters:**
- `inn` - ИНН организации (10 или 12 цифр)
- `provider` (опционально) - провайдер API: `fns`, `dadata`, `spark`

**Example:**
```bash
GET /api/fns/search/7707083893?provider=fns
```

**Response:**
```json
{
  "items": [
    {
      "inn": "7707083893",
      "name": "ПУБЛИЧНОЕ АКЦИОНЕРНОЕ ОБЩЕСТВО \"СБЕРБАНК РОССИИ\"",
      "address": "117997, г Москва, ул Вавилова, д 19",
      "status": "active"
    }
  ]
}
```

#### `GET /api/db/search`

Поиск в локальной базе данных.

**Parameters:**
- `query` - поисковый запрос
- `type` - тип поиска: `inn` или `name`

**Example:**
```bash
GET /api/db/search?query=СВОБОДА&type=name
```

### Парсинг

#### `POST /api/parse`

Парсинг текстовых данных через нейросеть.

**Request:**
```json
{
  "raw_text": "ИНН: 7714431171, Название: АО СВОБОДА, Выручка 2024: 750 млн руб."
}
```

**Response:**
```json
{
  "inn": "7714431171",
  "short_name": "АО \"СВОБОДА\"",
  "financial_data": [
    {
      "year": 2024,
      "revenue": 750000
    }
  ]
}
```

#### `POST /api/parse/pdf`

Парсинг PDF документов.

**Request:** `multipart/form-data` с файлом

**Response:** JSON с извлеченными данными

#### `POST /api/parse/excel`

Парсинг Excel файлов.

**Request:** `multipart/form-data` с файлом

**Response:** JSON с извлеченными данными

## 🎓 Как это работает

### 1. Сбор данных

```
Пользователь → Frontend → Backend → Внешние API
                                  ↓
                             База данных
```

**Источники данных:**
- API ФНС (ЕГРЮЛ/ЕГРИП)
- Загруженные документы (PDF, Excel)
- Ручной ввод

### 2. Обработка документов

```
Документ → Извлечение текста → Промпт + LLM → Структурированные данные
  (PDF)                          (Gemma 3)          (JSON)
```

**Процесс парсинга:**
1. Извлечение текста из документа
2. Формирование промпта с инструкциями
3. Отправка в LLM (Gemma 3:27B)
4. Получение JSON с данными
5. Валидация и очистка
6. Сохранение в БД

### 3. Визуализация

```
База данных → Backend API → Frontend → Chart.js → Интерактивные графики
```

**Типы визуализаций:**
- Bar charts (столбчатые)
- Line charts (линейные)
- Pie charts (круговые)
